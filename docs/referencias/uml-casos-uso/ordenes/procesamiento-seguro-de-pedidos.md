# Órdenes — Procesamiento seguro de pedidos

> 1 requerimiento interno relacionado del subproceso.

## Requerimientos internos relacionados

- El sistema debe prevenir la creación duplicada de órdenes por doble envío del formulario.
  - Tipo: regla de protección interna.
  - Disparador: se recibe un envío de formulario de orden que puede repetirse.
  - Actor directo: no aplica.
  - Representación: regla transversal trazada en este documento; no se asigna a un único caso base porque protege todos los flujos de creación de órdenes.
