# Gestión de Usuarios y Acceso — Compatibilidad de navegación de cuenta

> 1 requerimientos internos relacionados del subproceso.

## Requerimientos internos relacionados

- El sistema debe redirigir pantallas públicas antiguas de cuenta a sus pantallas actuales.
  - Tipo: redirección interna.
  - Disparador: se solicita una ruta pública antigua de cuenta.
  - Actor directo: no aplica.
  - Contexto: ruta heredada solicitada.
  - Representación: compatibilidad interna de navegación.
